# Ge/SiGe Hole Spin Qubit Simulations

Research simulation repository for the annular-arc Ge/SiGe double-quantum-dot project.

This repository is intended to archive QTCAD-based work on:
- electrostatics and confinement,
- double quantum dots and tunnel coupling,
- charge stability,
- Zeeman response and the observable G = g^T g,
- magnetic-field sweet spots,
- electrical susceptibility and charge-noise dephasing,
- T2*,
- phonon-limited T1,
- coarse/baseline/fine mesh convergence.

## Current repository state

This GitHub copy is a **recovered snapshot** from the ChatGPT workspace, not yet the complete local QTCAD project directory. The original workstation project contains additional meshes, HDF5/NPZ checkpoints, production scripts, figures, and final numerical outputs that are not available as files inside this chat environment.

Files in this repository are labeled accordingly. Missing local files should be copied from the original AnnularArc_SweetSpot_DQD_Ge directory rather than reconstructed from memory.
